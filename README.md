# glass-grid-bg

A reusable background component for containers: a grid of glass tiles over an animated
background layer. Whatever moves behind the tiles gets refracted, frosted and dispersed
by the glass.

Work in progress — see `/lab` for the live tuning panel.

## Dev

```bash
npm install
npm run dev        # open http://localhost:5173/lab
npm run typecheck
npm run lint
```
